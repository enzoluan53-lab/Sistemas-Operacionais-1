# Aula 01 – Apresentação da Disciplina e Introdução aos Sistemas Operacionais

## Objetivo da Aula

A primeira aula apresentou a disciplina de Sistemas Operacionais, sua metodologia de ensino, critérios de avaliação e os principais conteúdos que serão estudados durante o semestre. Também foi feita uma introdução aos conceitos fundamentais de Sistemas Operacionais.

---

## O que é um Sistema Operacional?

Um Sistema Operacional (SO) é o software responsável por gerenciar os recursos de hardware e software do computador, funcionando como uma interface entre o usuário e a máquina.

### Exemplos
- Windows
- Linux
- macOS
- Android
- iOS

---

## Estrutura dos Sistemas Operacionais

Os Sistemas Operacionais possuem uma organização interna que facilita seu funcionamento.

### Kernel
O kernel é o núcleo do sistema operacional e possui acesso direto ao hardware. Ele é responsável pelo gerenciamento dos principais recursos do computador.

### Modos de Operação

- **Modo Usuário:** executa programas comuns com acesso limitado aos recursos.
- **Modo Kernel:** possui privilégios elevados e acesso total ao hardware.

### Modelos de Kernel

- Monolítico
- Modular

---

## Escalonamento de Processos

O escalonamento determina qual processo será executado pela CPU e por quanto tempo.

### Objetivos

- Melhor desempenho
- Justiça entre processos
- Redução do tempo de resposta

### Algoritmos apresentados

- FIFO (First In First Out)
- Round Robin
- Prioridade

---

## Gerenciamento de Memória

O Sistema Operacional administra a memória principal e a memória virtual.

### Memória Principal

- Alocação dinâmica
- Proteção de memória

### Memória Virtual

- Expansão lógica da memória RAM
- Paginação
- Segmentação
- Maior segurança e flexibilidade

---

## Gerenciamento de Recursos

O Sistema Operacional também é responsável por:

- Gerenciamento de dispositivos de entrada e saída (E/S);
- Organização dos sistemas de arquivos;
- Segurança do sistema;
- Virtualização para melhor aproveitamento dos recursos computacionais.

---

## Portfólio de Projetos

Foi destacado que manter um portfólio de projetos é importante para:

- Demonstrar habilidades práticas;

- Facilitar oportunidades de estágio e emprego;

## Critérios de Avaliação

## Atividade da Aula

Os alunos deverão:

1. Formar grupos de 3 a 5 integrantes;
2. Entregar os nomes dos participantes;
3. Criar um repositório no GitHub;
4. Elaborar um resumo da Aula 01 em Markdown (.md);
5. Produzir uma linha do tempo dos Sistemas Operacionais utilizando um mapa mental na ferramenta Miro e posteriormente convertê-la para Markdown.

## Conclusão

A aula apresentou a estrutura da disciplina e introduziu os conceitos fundamentais dos Sistemas Operacionais.
